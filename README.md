# التزاماتي

حاسبة التزامات شهرية بسيطة: اكتب ميزانيتك وبنودك، وعلّم على اللي دفعته.

- صفحة واحدة `index.html` بدون مكتبات خارجية
- البيانات تنحفظ على جهاز المستخدم فقط (`localStorage`)
- زر "الشهر الجاي" ينقل البنود للشهر اللي بعده
- نسخ احتياطي واسترجاع عن طريق النسخ واللصق

## التثبيت كتطبيق
- أندرويد: افتح الرابط في `Chrome` ← القائمة ⋮ ← تثبيت التطبيق
- آيفون: افتح الرابط في `Safari` ← زر المشاركة ← إضافة إلى الشاشة الرئيسية
