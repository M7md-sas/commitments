# التزاماتي

تطبيق لإدارة الالتزامات الشهرية وتحليل المصروفات.

- **الالتزامات:** أدخل الميزانية الشهرية والالتزامات، وعلّم على المدفوع منها.
- **تحليل المصروفات:** الصق الرسائل البنكية ليتم ربط العمليات بالالتزامات وتصنيف المصروفات الأخرى، ومطابقتها مع الرصيد الحالي. تبدأ الفترة من تاريخ إيداع الراتب.
- **الخصوصية:** تُحفظ البيانات على الجهاز فقط (`localStorage`)، ولا تُرسل إلى أي خادم.

## التثبيت
- أندرويد: افتح الرابط في متصفح `Chrome`، ثم من القائمة اختر "تثبيت التطبيق".
- آيفون: افتح الرابط في متصفح `Safari`، ثم من زر المشاركة اختر "إضافة إلى الشاشة الرئيسية".
